# 予算案

藤原先生の考案した推奨構成を基に、使用する資源を以下にまとめる。
為替レートは1ドル=159円で換算している。

## AWS EC2

[AWS Pricing Calculator](https://calculator.aws/#/)を使用して見積もると、以下のようなコストが予想される。
※従量課金制のため、使用時間は余裕を持って見積もっている。

|リージョン|インスタンス|想定使用時間|ストレージ|ストレージ容量|スナップショット|
|-|-|-|-|-|-|
|アジアパシフィック(大阪)|t4g.xlarge|8時間/日|汎用SSD(gp3)|120GB|6GB|

- インスタンス：t4g.xlargeはArmCPU、4基の仮想プロセッサ、16GiBのメモリ搭載。
- 想定使用時間：1日8時間、月に240時間使用すると仮定。
- ストレージ容量：OS・コンテナで20GB想定。開発で5人100GB使用すると仮定。
- スナップショット：容量の5%をスナップショットに使用すると仮定。保険として毎日スナップショットを取得する。

1ヵ月あたりのコストは
- EC2インスタンス： **$42.36** 
- EBSストレージ： **$3.80** 
- スナップショット： **$3.46** 

合計 **$49.62** となる。これを日本円に換算すると、1ヵ月あたり **約7,890円** となる。

開発期間を6月から9月の4ヵ月とすると、AWSの総コストは **約31,560円** となる。

### 補足 定額のチケットプラン

[大学生協](https://software.univcoop.or.jp/item/13003)や[NHNテコラス](https://nhn-techorus.com/c-chorus/lp-publicsector/)は、1年分のAWS定額チケットプランを提供している。これらのプランを利用することで、従量課金制のデメリットであるコストの変動を抑えることができ、コストの予測がしやすくなる。
ただ、これらのページには料金は記載されているが、スペックに関しては後から問い合わせる必要があるため、場合によっては従量課金より高くなる可能性もある。今回はスペックを考慮せず料金を見積もるが、実際に利用する際にはスペックを確認し、コストと性能のバランスを考慮して選択する必要がある。

|提供元|チケットプラン|料金|
|-|-|-|
|大学生協|AWSメンバーズバウチャーチケットサービス|**99800円**|
|大学生協|AWSスターターチケット（オプション）|**69800円**|
|大学生協|AWSアカウント転入チケット（オプション）|**9900円**|
|NHNテコラス|AWS総合支援サービス C-Chorus|**50000円**|

## Claude API

[Anthropic社の料金体系](https://claude.com/ja/pricing#api)に基づき、以下のようなコストが予想される。
※APIは入力および出力トークン数に応じた従量課金制のため、AWSと同じく使用量は余裕を持って見積もっている。

|モデル名|入力Token|出力Token|キャッシュ書き込み|キャッシュ読み取り||
|-|-|-|-|-|-|
|Opus 4.7|$5.00/MTok|$25.00/MTok|$6.25/MTok|$0.50/MTok||
|Sonnet 4.6|$3.00/MTok|$15.00/MTok|$3.75/MTok|$0.30/MTok||
|Haiku 4.5|$1.00/MTok|$5.00/MTok|$1.25/MTok|$0.10/MTok||

1回のAPI呼び出しでのToken消費量は以下の基準で算出する。

例：100行のTypeScriptコードを出力させる場合
- 入力Token
    - システムプロンプト：500Token
    - ユーザープロンプト：300Token

- 出力Token
    - 生成されたコード：1500Token
    - 説明文：400Token

1回のAPI呼び出しでのToken消費量は
- 入力： **800Token**
- 出力： **1900Token**

合計 **2700Token** となる。これをモデルごとの料金に当てはめると、API呼び出しでのコストは以下のようになる。
9000回という回数は、5人が1日あたり15回のAPI呼び出しを4ヵ月間行うと仮定して算出している。
|モデル名|1回あたりのコスト|1000回あたりのコスト|9000回あたりのコスト|9000回あたりのコスト(日本円)|
|-|-|-|-|-|
|Opus 4.7|$0.0515|$51.50|$463.50|**約73,700円**|
|Sonnet 4.6|$0.0309|$30.90|$278.10|**約44,220円**|
|Haiku 4.5|$0.0103|$10.30|$92.70|**約14,740円**|
